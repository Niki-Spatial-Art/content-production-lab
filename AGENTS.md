# Content Production Lab Instructions

## Scope

This repository is for public, reusable content and creative production workflows.

Use it for:

- article and newsletter workflows
- short-video scripts
- creative campaign directions
- ad copy and launch materials
- image prompt systems
- publishing templates
- public content-production tools and resource indexes

Do not publish private chat transcripts, private client details, unpublished personal schedules, or sensitive identity information.

## Preferred Codex Routing

- Use Creative Production-style workflows for concepts, copy, visual direction, and asset prompts.
- Use `imagegen` when bitmap visuals would make the output more useful.
- Use `Documents` for long-form drafts and structured reports.
- Use `Presentations` for pitch decks or campaign decks.
- Use `Browser` or `playwright` when verifying a local content page or web preview.

## Output Style

- Produce concrete options, not abstract brainstorming.
- Include audience, message, format, visual direction, and next action.
- Keep reusable templates separate from one-off drafts.
- Make public-facing examples privacy-safe.

## Skill Promotion

If the same content workflow repeats three or more times, propose turning it into a Codex skill or playbook.
