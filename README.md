# Content Production Lab

内容生产方向的公开收藏仓库。

这个仓库用于整理公众号、长文、短评、视频脚本、选题库、发布流程、图表工具和内容自动化。目标是把研究和想法变成稳定可发布的内容系统。

## What Goes Here

- 公众号文章流程
- 选题库和内容地图
- 写作、排版、图表、发布工具
- 视频脚本和短内容模板
- 值得收藏或 fork 的内容生产 GitHub 项目

## Structure

- `repos.md`: 内容生产相关 GitHub 仓库索引
- `playbooks/`: 选题、写作、发布、复盘流程
- `templates/`: 文章、脚本、选题、仓库登记模板
- `archive/`: 历史稿件、阶段性判断和旧流程
